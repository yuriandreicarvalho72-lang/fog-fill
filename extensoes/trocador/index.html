Trocador

Troque a arte de tokens e objetos entre imagens guardadas neles. Rápido: botão direito no item → Trocar imagem.

Com Gatilhos e Estados

Gatilhos: efeito Trocar imagem (Trocador). Escolha os itens (ou "+ quem ativou") e a imagem pelo nome, ou próxima/anterior. Ex.: pisou na armadilha → token vira "Ferido".

Estados: marque a propriedade Imagem no grupo e troque a arte com o Trocador enquanto edita cada estado. O Estados mostra o nome da imagem de cada item. Ex.: "Disfarce" → todos os tokens do grupo vestem a arte "Disfarçado".

Os nomes das imagens importam: tokens diferentes com uma imagem de mesmo nome ("Ferido") trocam juntos.
